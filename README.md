# 🛸 Gustav - Long Range & High-Speed Micro Quad

Gustav is a custom build based on the **Crux3** frame, designed to be a versatile beast. It switches from an incredible 35-minute endurance cruiser on 1S to a 160 km/h rocket on 2S.

---

## 🛠 Technical Specifications

| Component | Detail |
| :--- | :--- |
| **Frame** | Crux3 frame + canopy |
| **FC / AIO** | HGLRC Specter 10A |
| **Motors** | HGLRC SPECTER 1202.5 11000KV |
| **Camera** | Caddx Ant 1200TVL |
| **Propellers** | Gemfan Hurricane 3018 (2-blade) |
| **VTX** | 400 mW |
| **RX** | ELRS 2.4 GHz |
| **VTX Antenna** | Linear |

---

## 🔋 Performance & Power

Gustav has a dual personality depending on your battery choice:

### Endurance Mode (1S)
* **Battery:** JP30 3000mAh
* **AUW:** 92 g
* **Flight Time:** ~**35 minutes**
* **Hover:** 35% throttle
* **Top Speed:** ~80 km/h

### Beast Mode (2S)
* **Battery:** Standard 2S LiPo
* **AUW:** ~72 g
* **Flight Time:** ~5 minutes max
* **Hover:** 30% throttle

---
